# Obsidian 错题管理系统

以**截图**为核心的 Obsidian 错题管理方案：截图错题 → 快捷键录入 + 打标签 → 仪表盘定位薄弱点 → 随机组卷自测 → 标记掌握程度（自动安排下次复习）。

## 功能

- **一键录入**：`Ctrl+Shift+E` 自动生成带 frontmatter 的错题笔记（考点 / 错因 / 难度 / 答案 / 复习字段）
- **智能建议录入**：考点 / 错因从历史词库弹出可打字过滤的建议列表，支持连续添加多个，新词自动入库
- **规范词表**：`脚本/规范词表.json` 集中维护考点与错因，从源头避免同义词分裂
- **仪表盘**：今日待复习、掌握程度分布、难度分布、薄弱考点 TOP 10、错因分布、每周新增趋势
- **随机组卷**：按难度 / 掌握程度 / 考点 / 错因筛选，默认只抽到期的题，支持防重复（默认 2 天内不重复抽）
- **复习调度**：标记掌握程度时自动安排下次复习，间隔按 1 → 3 → 7 → 15 → 30 天递进
- **错因与复盘**：录入时记录错因，每道题内置「我的复盘」区
- **便携即用**：`.obsidian` 已预装 Dataview、Templater、QuickAdd 及全部配置，打开即用

## 快速开始

1. 克隆或下载本项目
2. 用 Obsidian「打开文件夹作为 Vault」选择项目文件夹
3. 按 `Ctrl+Shift+E` 录入第一道错题，粘贴截图
4. 打开「错题仪表盘」查看统计，打开「试卷/随机组卷」自测

详细用法见 [Obsidian错题管理系统使用指南.md](./Obsidian错题管理系统使用指南.md)。

## 文件结构

```
错题本/              ← 错题笔记（个人数据，已被 git 忽略）
错题原图/            ← 截图原图（个人数据，已被 git 忽略）
试卷/随机组卷.md      ← 随机组卷工具
模板/错题模板.md      ← 录入模板
脚本/update-mastery.js ← 更新掌握程度脚本
脚本/规范词表.json     ← 考点/错因词库（录入时自动维护）
错题仪表盘.md         ← 统计面板
Obsidian错题管理系统使用指南.md ← 完整使用指南
```

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+E` | 录入新错题 |
| `Ctrl+Shift+M` | 更新掌握程度（复习次数 +1，自动安排下次复习） |

## 说明

- `错题本/` 与 `错题原图/` 是系统的数据目录，已保留在仓库中（用 `.gitkeep` 占位）；目录里的笔记和图片会被 git 忽略，只留在本地，不会上传到仓库
- 本项目依赖社区插件：Dataview、Templater、QuickAdd（已预装配置）
- 版本更新说明见 [CHANGELOG.md](./CHANGELOG.md)
